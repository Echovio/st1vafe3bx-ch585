# 数据格式与边界

本仓库不包含真实受试者数据。默认演示由 `ml.baseline` 人工生成，不能用于证明设备精度、运动识别能力或临床效果。

真实数据输入使用一份 UTF-8 CSV，每行一条同步样本，必须包含以下列：

| 字段 | 说明 |
| --- | --- |
| `subject_id` | 参与者匿名编号；必须能区分不同人 |
| `trial_id` | 同一参与者内唯一的试次编号；跨采集会话不能复用 |
| `timestamp_us` | 本试次内递增的设备时间戳，单位微秒 |
| `label` | 单个试次的动作类别 |
| `accel_x_mg`, `accel_y_mg`, `accel_z_mg` | 三轴加速度，单位 mg |
| `vafe_lsb` | vAFE 左对齐的有符号 16 位原始码 |

CSV 每个试次只允许一种标签，时间戳不能重复。分窗前按试次分别排序，跳过内部存在采样间隔异常的窗口；间隔容差为标称间隔的 20%。采集前请先处理零时间戳、计数器回绕、丢包和标签边界；程序不会自动判定设备异常，也不会重采样。默认 800 Hz，实际不同需通过 `--sampling-rate` 指定。传感器零时间戳既可能是起始值，也可能表示缺失，不能仅凭该值自行判断。

使用真实数据前请核对授权、去标识化及公开范围。不要提交原始受试者数据、训练输出或敏感信息；先检查 `outputs/results.json` 是否含有参与者编号。

`ml.protocol.decode_frame()` 接受单个完整的 12 字节 A5 5B 帧，返回设备原始时间戳和左对齐通道值；不负责 BLE 分包重组、流同步、物理单位换算或转换为训练 CSV。
